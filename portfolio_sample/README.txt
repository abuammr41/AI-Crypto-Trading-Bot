PORTFOLIO SAMPLE - DISCLOSURE
==============================

Project_Cover_TradingBot.png is a self-made architecture/overview graphic
for this project, built for portfolio display purposes only.

It deliberately shows ONLY the bot's pipeline and feature set (scan, score,
enter, protect, exit; risk-management features) - it does NOT show any
trade history, profit/loss figures, or performance claims. This is a
trading tool and fabricating or implying real trading results would be
misleading, so none are shown here. Trading involves real financial risk.
